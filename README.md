# ST7735 Driver for ESP-IDF

A simple ST7735 display driver written in C for ESP-IDF.

![Demo](examples/demo.png)

## Features

- RGB565 colors
- Configurable SPI and GPIO pins
- Display orientation
- Pixels
- Lines
- Rectangles
- Circles
- Text
- Bitmaps
- Drawing windows
- Raw pixel data

## Examples

Example programs are available in the `examples/` directory.
